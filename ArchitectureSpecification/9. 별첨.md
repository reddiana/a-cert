## A. 전체 클래스 다이어그램 (5.2.2 Class Diagram)

5.2.2 본문에는 핵심 클래스와 멤버만 발췌한 개요 클래스 다이어그램을 수록하였습니다. 패키지별로 모든 필드·생성자·메소드(비공개 멤버 포함)와 전체 관계를 소스 코드와 1:1로 표기한 클래스 다이어그램은 다음과 같습니다. 다른 패키지의 타입은 멤버를 생략한 참조 박스로 표시하며, 클래스별 책임과 설계 포인트는 5.2.2.3의 표를 참조합니다.

### 표기 규칙

| 표기 | 의미 |
| :--- | :--- |
| `+` / `-` / `#` / `~` | public / private / protected / package-private |
| 밑줄 | static 멤버 |
| 기울임 | abstract 메소드 (인터페이스의 추상 메소드) |
| `{readOnly}` | final 필드 |
| «interface» / «enumeration» / «record» | 인터페이스 / 열거형 / Java record (record 구성 요소는 속성 칸에 표기하고 컴파일러 생성 접근자는 생략) |
| `Outer.Inner` | 중첩 타입 |
| 실선 + 열린 화살표 (역할명, 다중성) | 연관(Association): 필드 참조 |
| 실선 + 채운 마름모 | 합성(Composition): 전체 객체가 생명주기를 소유하는 부분 객체 |
| 클래스 변에 붙은 사각형 `[키: 타입]` | 한정자 연관(Qualified Association): `Map` 필드. 한정자(키) 값 하나로 대상 객체를 식별하며, 대상 쪽 다중성은 키 1개당 개수(`0..1`, 대기열이면 `0..* {ordered}`) |
| 실선 + ⊕ | 중첩(Nesting): 내부 타입 선언 |
| 점선 + 빈 삼각형 | 실현(Realization): 인터페이스 구현 |
| 실선 + 빈 삼각형 | 일반화(Generalization): 클래스 상속 |
| 점선 + 열린 화살표 + «stereotype» | 의존(Dependency): «create» 생성, «use» 사용, «read local view» 로컬 FSM 조회, «throw» 예외 발생 등 |
| 회색 점선 박스 (from 패키지) | 다른 패키지 타입 참조 (멤버는 해당 패키지 다이어그램 참조) |

- 한정자 연관은 값이 다이어그램의 클래스인 `Map` 필드에 적용했습니다: `ClusterStateMachine.requestResults[requestId]`, `LockStateMachine.locks[key]`, `LockStateMachine.waiters[key]`, `QueueStateMachine.inFlight[jobId]`, `JournalStateMachine.executions[executionId]`, `SocketNetworkTransport.outbound[peerId]`. 값이 `Long`·`String`·`CompletableFuture`·`Consumer`인 `Map` 필드(`RaftNode.matchIndex`, `RaftNode.pendingByIndex`, `Command.attrs` 등)는 속성 칸에만 표기합니다.
