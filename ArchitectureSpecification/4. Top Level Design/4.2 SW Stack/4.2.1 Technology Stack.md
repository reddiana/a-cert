**1. Core Runtime & Language**
- **Java Development Kit (JDK):** OpenJDK 17 LTS (Spring Boot 3.x와의 상위 호환성 및 사내 인프라 배포 범용성 준수)
- **Standard Java API:** 
  - `java.util.concurrent`: 동시성 제어, Raft 상태 머신 스레드 관리, 인메모리 Lock/Queue 운영 (`DD-01`, `DD-02`, `DD-03`)
  - `java.net` / `java.nio`: Raft P2P TCP 소켓 통신(Leader Election, Lock, Queue, WAL 복제) (`DD-01` ~ `DD-05`)
  - `java.io` / `java.nio.file`: 로컬 WAL(Write-Ahead Log) 파일 I/O 및 fsync 기반 내구성 쓰기 (`DD-04`, `DD-05`)
  - `java.sql` 및 `javax.sql`: RDBMS JDBC 트랜잭션 (DB Write-Behind 동기화, 하위 호환 스키마) (`DD-04`, `DD-05`)

**2. Build & Infrastructure**
- **Build Tool:** Gradle (Java 17 표준 빌드 환경 지원 및 멀티 모듈 의존성 제어)
- **Database Connection Pool:** 수요처 Spring Boot 애플리케이션의 `DataSource`(기본 HikariCP)를 재사용합니다. 엔진은 커넥션 풀을 직접 생성하지 않으며, `DataSource` Bean이 있을 때만 Write-Behind 동기화를 활성화합니다 (`DD-05`).
- **의존성 정책:** Redis, Zookeeper, Hazelcast 등 외부 분산 코디네이터 및 유료 라이선스 모듈은 사용하지 않습니다 (`CR-01`, `NR-01`, `NR-03`). 합의·전송·WAL·FSM 코어(`consensus`, `consensus.transport`, `storage`, `fsm`)는 JDK 17 표준 API와 로깅 API(SLF4J)만 사용하고, 수요처 연동 계층(자동 구성, Readiness, DB 반영)은 Spring Boot 표준 모듈만 사용합니다 (5.2.1).

| 구분 | 의존성 | 범위 | 라이선스 | 용도 |
| :--- | :--- | :--- | :--- | :--- |
| 필수 | `org.springframework.boot:spring-boot-autoconfigure` | implementation | Apache-2.0 | 엔진 자동 구성 (`DD-06`) |
| 필수 | `org.slf4j:slf4j-api` | implementation | MIT | 로깅 API |
| 선택 | `org.springframework:spring-jdbc` | compileOnly (수요처 제공 시 활성) | Apache-2.0 | Write-Behind JDBC 반영 (`DD-05`) |
| 선택 | `org.springframework.boot:spring-boot-actuator` | compileOnly (수요처 제공 시 활성) | Apache-2.0 | Raft Readiness Probe (`DD-07`) |

- **Raft P2P 통신 포트:** DD-01~DD-05 공유 단일 포트(예: 7800) 개방. K8s Headless Service를 통해 노드 간 DNS 기반 자동 디스커버리 구성.
