### 배경  
- 당사 Batch Job Scheduler 재사용자산 "BatchService"가 의존하던 분산 처리 오픈소스 라이브러리 "Hazelcast"가 유료화로 정책 변경됨에 따라, 
- 특정 벤더나 라이브러리에 종속되지 않는 지속 가능한 기술적 대안이 필요함. 

![[1. Project Overview/BatchService개념도.svg]]
### 목표  
- 외부 라이브러리 없이 Java Standard 기술만으로 클러스터 기반의 Self-Healing, Distributed Queue, Distributed Lock 기능을 구현하여 저비용·고효율의 독자적인 배치 스케줄러 아키텍처 확보.
