### 4.2.1 Technology Stack

본 프로젝트는 외부 라이브러리(Hazelcast 등)에 종속되지 않고 Java Standard 기술만을 사용하여 분산 배치 스케줄러 아키텍처를 구현하는 것을 목표로 합니다.

#### 1. Core Runtime
- **Java Development Kit (JDK):** Java 17 이상 (또는 프로젝트 표준 버전)
- **Standard Library:** `java.util.concurrent`, `java.net`, `java.nio` 등 표준 패키지 활용

#### 2. 주요 분산 기능 구현 기술
- **Self-Healing (Cluster Heartbeat / Membership):**
  - UDP Multicast 또는 TCP Socket 통신 (`java.net.DatagramSocket`, `java.net.ServerSocket`)을 통한 노드 감지 및 상태 동기화
- **Distributed Queue:**
  - Java의 `BlockingQueue` 인터페이스 계열 및 커스텀 저널링/분산 메커니즘 설계
- **Distributed Lock:**
  - Database(JDBC/Standard SQL) 활용 혹은 TCP 소켓 통신 기반의 락 조정자(Coordinator) 구현

#### 3. Build & Dependency 관리
- **Build Tool:** Maven 또는 Gradle (의존성을 최소화하여 빌드본 크기 경량화)
- **External Dependencies:** (없음 - Java Standard API만 사용함을 원칙으로 함)
