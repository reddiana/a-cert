### 2.5 시스템 가정 사항 (Assumption of the System)

BatchService 아키텍처 설계 및 구현의 전제가 되는 기술적/환경적 가정 사항(Assumption)을 정의함.

| ID | 가정 사항 | 상세 설명 | 비고 |
| --- | --- | --- | --- |
| ASM-01 | **TCP 유니캐스트 기반 네트워크** | K8s 및 클라우드 방화벽 제약을 고려하여, 클러스터 노드 간 통신은 UDP 멀티캐스트 대신 명시적 포트를 통한 **TCP 유니캐스트 소켓** 통신을 기본으로 가정함. | 멤버십 관리의 제약사항 우회 |
| ASM-02 | **NTP 기반 노드 간 시간 동기화** | 시간차 기반의 스케줄 실행 및 분산 락 만료 임대 시간(Lease Time) 산정을 위해, 클러스터 노드 간의 서버 시스템 시간 오차는 **최대 1초 이내**로 동기화되어 있다고 가정함. | 동시성 정확도 보장 |
| ASM-03 | **고가용성 DB 인프라** | 스케줄 정보 적재 및 분산 동시성 제어의 이중 안전장치(저널링 및 하이브리드 동기화) 역할을 하는 메타 RDBMS가 이중화 구성 등으로 상시 작동하고 있다고 가정함. | 상태 영속화 및 장애 복구 |
| ASM-04 | **JDK 17 런타임 호환성** | 배치 스케줄러가 구동되는 JVM 환경은 최소 **JDK 17 이상**의 버전 규격을 보장하며, Java Standard API 이외의 외부 서드파티 라이브러리 탑재는 불필요함을 가정함. | 독자 아키텍처 구동 규격 |
