# Project Rules

## Documentation and Response Style Guidelines

- **LLM 특유의 과장된 표현 사용 금지**
  - "완벽히", "완벽하게", "극대화", "제로화", "최고 수준", "최상", "근본적 해결", "매우 우수" 등 과장되거나 홍보성/감정적인 수식어를 절대 사용하지 않습니다.
- **공식 문서 표준의 객관적·담담한 어조 유지**
  - 모든 설명, 기술 문서, 코드 주석 및 답변은 객관적인 사실과 기술적 표현 위주의 담담한 어조로 작성합니다.
  - 평가 등급은 '우수', '적합', '부적합' 등으로 절제하여 표현하고, 정량적/정성적 효과는 '향상', '최소화', '방지', '경감' 등의 객관적 용어로 명확히 기술합니다.
